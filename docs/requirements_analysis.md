## 1. 체중(BMI) · 나이대별 비즈니스 규칙

### 1.1 BMI 산출

| 항목 | 규칙 |
|------|------|
| 입력 필드 | `id`, `age`(세), `weight`(kg), `height`(cm) — CSV `shealth.dat` |
| 변환 | 키(m) = `height / 100.0` |
| 공식 | `BMI = weight / (height_m)²` |
| 부동소수 | `double` 연산; 테스트 시 `EXPECT_NEAR` 허용 오차 명시 권장 |

### 1.2 BMI 4분류 (README 도메인 기준)

| 분류 | README 조건 | 구현 시 권장 구간 (반열린) | `getBmiRatio` type |
|------|-------------|---------------------------|-------------------|
| 저체중 (Underweight) | 18.5 **이하** | `bmi ≤ 18.5` | `100` |
| 정상체중 (Normal) | 18.5 **초과**, 23 **미만** | `18.5 < bmi < 23` | `200` |
| 과체중 (Overweight) | 23 **이상**, 25 **미만** | `23 ≤ bmi < 25` | `300` |
| 비만 (Obesity) | 25 **이상** | `bmi ≥ 25` | `400` |

**경계값 매트릭스 (분류 단위 테스트 필수)**

| BMI 값 | 기대 분류 |
|--------|-----------|
| 18.5 | 저체중 |
| 18.5000001 … 22.999… | 정상 |
| 23.0 | 과체중 |
| 24.999… | 과체중 |
| 25.0 | 비만 |

> **현행 코드 주의**: `SHealth.cpp` 비만 조건이 `bmis[i] > 25` 이면 **BMI=25.0 미분류** 가능. README·`.cursorrules`는 `≥25` — 구현·TC에서 반드시 정합.

### 1.3 연령대(나이대) 정의

| 연령대 라벨 | `ageClass` (API) | 포함 나이 `age` | 루프 변수 `a` (현행 코드) |
|------------|------------------|-----------------|---------------------------|
| 20대 | 20 | 20 ≤ age < 30 | 20 |
| 30대 | 30 | 30 ≤ age < 40 | 30 |
| 40대 | 40 | 40 ≤ age < 50 | 40 |
| 50대 | 50 | 50 ≤ age < 60 | 50 |
| 60대 | 60 | 60 ≤ age < 70 | 60 |
| 70대 | 70 | 70 ≤ age < 80 | 70 |

- 통계 집계 대상: 위 6개 연령대만 (`a = 20; a <= 70; a += 10`).
- **20대 미만·80세 이상** 사용자: 데이터에는 적재되나, 연령대별 **비율 집계 분모에 포함되지 않음** (현행 설계). 요구 변경 시 명시적 스펙 추가 필요.

### 1.4 연령대 × BMI 분류 — 통계 출력 규칙

| 차원 | 규칙 |
|------|------|
| 집계 단위 | 각 연령대 내 사용자 1인 = 1표본 |
| 지표 | 카테고리별 **인원 비율(%)** = `(카운트 / 연령대 총 인원) × 100` |
| 조회 API | `double getBmiRatio(int ageClass, int type)` — `ageClass` ∈ {20,30,40,50,60,70}, `type` ∈ {100,200,300,400} |
| 합계 | 이론상 4분류 비율 합 ≈ 100% (미분류 인원이 있으면 < 100%) |
| 파이프라인 | `calculateBmi(filename)` → 파일 로드 → 체중 보정 → BMI 계산 → 연령대별 집계 → `count` 반환 |

### 1.5 결측 체중 보정 (현행 구현 요구)

| 조건 | 동작 |
|------|------|
| 결측 표시 | `weight == 0.0` (kg) |
| 보정값 | **동일 연령대** 내 `weight != 0` 인 표본의 **산술 평균** |
| 평균 산출 시 | `weight == 0` 인 행은 평균 계산에서 **제외** |
| 적용 순서 | 연령대별(20→70) 평균 산출 후, 해당 연령대 내 `weight==0` 행에 일괄 대입 → 이후 BMI 계산 |
| 키(height) 결측 | README Activity 4 — **별도 요구**(아래 §4) |

### 1.6 체중 · 나이대 교차 규칙 요약표

| 연령대 ↓ / BMI → | 저체중 | 정상 | 과체중 | 비만 |
|------------------|--------|------|--------|------|
| 20대 | % of 20~29세 | % | % | % |
| 30대 | % of 30~39세 | % | % | % |
| 40대 | % of 40~49세 | % | % | % |
| 50대 | % of 50~59세 | % | % | % |
| 60대 | % of 60~69세 | % | % | % |
| 70대 | % of 70~79세 | % | % | % |

## 2. 문자열 비교 · 분기 시 주의점 (`std::string` 등)

본 프로젝트는 Gilded Rose처럼 **아이템 이름 문자열 분기**가 아니라 **CSV·파일 경로·토큰 파싱**이 핵심이다. C++17 구현·QA 시 아래를 준수한다.

### 2.1 CSV · 파일 I/O

| 주제 | 권장 · 주의 |
|------|-------------|
| 파일 경로 | `calculateBmi(const std::string& filename)` — 존재하지 않으면 현행: `cerr` 로그 후 `0` 반환. 테스트는 임시 파일·픽스처 경로 사용 |
| 헤더 행 | 첫 줄 `id,age,weight,height` **스킵** (`getline` 1회 후 데이터 루프) |
| 구분자 | `split(line, ',')` — `std::getline(iss, token, ',')` |
| 토큰 개수 | 유효 행은 **4토큰** 가정. 부족 시 `stoi`/`stod` **예외** (`std::invalid_argument`, `std::out_of_range`) |
| 빈 줄 | `tokens.empty()` 시 현행 코드는 **`break`로 전체 읽기 중단** — 데이터 중간 공백 줄이 있으면 이후 레코드 무시됨. 스펙: 빈 줄 **skip** vs **abort** 중 하나로 고정 후 TC화 |
| 공백 | `split`은 trim 없음 → `" 66"` 은 파싱되나 `"66 "` 은 `stod` 실패 가능. 필요 시 trim 유틸 또는 `std::stringstream` + 검증 |

### 2.2 문자열 비교 일반 (향후 확장·리팩토링)

| 패턴 | 위험 | 권장 |
|------|------|------|
| `str == "Normal"` | 대소문자·공백·로캘 | 도메인 enum / `enum class BmiCategory` + 정수 `type` (현행 `100~400`을 enum class로 승격) |
| `str.find("Conjured")` | 부분 문자열 오매칭 (`"NotConjured"` 등) | 접두사 규칙이면 `starts_with`(C++20) 또는 `compare(0, n, prefix)==0` |
| `find != npos` vs `== 0` | `find` 위치 검사 누락 | 접두사·접미사는 명시적 길이 비교 |
| `strcmp` / C 문자열 | 길이·인코딩 | C++17에서는 `std::string_view` + 명시 비교 |
| 로캘 의존 분기 | 플랫폼별 결과 상이 | BMI·연령은 **숫자만**으로 분기; 문자열은 I/O·라벨 출력에만 사용 |

### 2.3 숫자 분기 (실제 핵심 분기)

| 항목 | 현행 | QA 포인트 |
|------|------|-------------|
| 연령대 | `age >= a && age < a + 10` | 경계 29/30, 19/20, 69/70, 79/80 |
| 결측 체중 | `weight == 0.0` | `-0.0`, `1e-300` 은 결측 아님 — `== 0.0` 명시 |
| `getBmiRatio` | `ageClass`, `type` 정수 다중 `if` | 잘못된 코드 시 `0.0` 반환 — **실패와 0% 구분 불가**. `std::optional` 또는 `bool`+out-param 검토 |
| Magic `type` | 100/200/300/400 | `enum class BmiCategory` + `static_cast` 로 오타 방지 |

### 2.4 `split` 구현 관련

- **단일 책임**: 범용 파서로 두되, `SHealth` God Class와 분리하는 것이 테스트·재사용에 유리.
- **빈 필드**: `1,2,,4` → 빈 토큰 생성; 상위에서 토큰 수·빈 문자열 검증.

## 4. 신규 요구사항 (README Activity 4)

> 템플릿의 “Conjured”에 대응: 본 프로젝트 **기능 개선** 항목. 구현 전 **테스트 선행(TDD)**.

| ID | 요구사항 | C++ 구현 관점 | 테스트 포인트 |
|----|----------|---------------|---------------|
| N1 | **특정 연령대** BMI 분포 비율 | `getBmiRatio(ageClass, type)` 정교화 또는 `getDistribution(AgeBand)` | 단일 연령대 Known-answer, 4 type 합 |
| N2 | **Height == 0** 연령대 평균 키 보정 | 체중 0 보정과 동일 패턴: 밴드 평균 → impute → BMI | 전원 height 0, 일부만 0, `ageCount==0` |
| N3 | **BMI 정상 범위** 사용자 목록 | `18.5 < bmi < 23` 필터, `std::vector<UserId>` 또는 id 목록 반환 | 빈 목록, 경계 18.5/23 제외·포함 |
| N4 | **전체 사용자** 대비 BMI 범주 비율 | 연령 무관 전체 집계 API (4비율) | 전체 합 100%, 연령대 API와 값 다름 검증 |
| N5 | (리팩토링) SRP 책임 분리 | `load` / `imputeWeight` / `imputeHeight` / `computeBmi` / `aggregate` 분리 | 단계별 `TEST_F`, mock CSV |

**N2 상세 스펙(제안)**

1. `height == 0.0` 을 결측으로 간주 (체중 0과 동일 sentinel).
2. 동일 연령대에서 `height != 0` 표본 평균으로 대체.
3. 보정 순서: README 미명시 시 **체중 보정 → 키 보정 → BMI** 로 고정하고 TC에 기록.
4. 키·체중 모두 0인 연령대: 0 나눗셈 방지 (§3.3 A1).

22. 서로 다른 연령대 보정이 섞이지 않음 (30대 0은 30대 평균만).

### 5.5 `getBmiRatio` · 연령대 통계
